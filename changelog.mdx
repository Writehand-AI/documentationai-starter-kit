## Recent Updates

<Callout kind="info">
  Coterie is early and moving fast. This log covers the most recent, user-facing changes.
</Callout>

<Update label="2026-08-18" description="Coterie Assistant &amp; email overhaul" tags={["feature"]}>

- Added the Coterie Assistant — a per-community AI chatbot scoped to a member's own data, using a creator-supplied OpenAI key.
- Rebuilt transactional email on Postmark, with per-tenant template overrides.

</Update>

<Update label="2026-08-16" description="Onboarding, Discover, and custom menu" tags={["feature"]}>

- Added the Discover page for browsing public Coteries across the platform.
- Shipped the member onboarding flow (niche selection, rules acceptance).
- Added support for creators to add custom links to the member sidebar.
- Integrated the form builder for custom application questions.

</Update>

<Update label="2026-08-15" description="Navigation cleanup &amp; admin hub" tags={["improvement", "bugfix"]}>

- Flattened the sidebar navigation and added a dedicated Admin hub.
- Added an About/white-label section to Discover.
- Fixed two access-control bugs affecting cross-tenant data exposure.

</Update>

<Update label="2026-08-14" description="Custom domains &amp; white-label (v1)" tags={["feature"]}>

- Shipped the first version of custom domains and white-label branding, letting a creator run their community under its own domain.
- First production deployment, running on Fly.io.

</Update>
