## How to Upgrade

Upgrading Coterie ensures you get the latest features and security patches. Follow these steps to update safely.

<Callout kind="tip">
  Test upgrades in a staging environment first.
</Callout>

<Steps>
  <Step title="Backup Your Data" icon="database">

    Export your communities and member data.

````bash
coterie-cli backup --output=backup.json
````

  </Step>
  <Step title="Update Package" icon="package">

    Use your package manager to install the latest version.

    <CodeGroup tabs="npm,yarn">
````bash
npm update @coterie/core@latest
````
````bash
yarn upgrade @coterie/core@latest
````
    </CodeGroup>

  </Step>
  <Step title="Run Migrations" icon="git-merge">

    Apply database changes if applicable.

````bash
coterie migrate
````

  </Step>
  <Step title="Restart Services" icon="refresh-cw">

    Restart your Coterie instance.

````bash
systemctl restart coterie
# or
docker-compose restart
````

  </Step>
</Steps>
